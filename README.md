# tres-en-raya-cpp

Juego del tres en raya para jugar en la terminal, escrito en C++.

Es mi primer proyecto de aprendizaje. Lo hago para practicar arrays, funciones y strings, y para aprender a usar Git y GitHub.

## Qué hará
- Mostrar el tablero por pantalla
- Dos jugadores por turnos
- Validar las jugadas
- Detectar ganador y empate
